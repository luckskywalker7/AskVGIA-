Démarrage rapide

Passez d'une vidéo brute à des réponses instantanées et sourcées en moins de 5 minutes. Ce guide vous accompagne de la création du compte jusqu'à votre première requête réussie.

i

Beta gratuite. Toutes les fonctionnalités sont disponibles pendant la Beta, sans carte bancaire. Les Early Adopters bénéficient d'un tarif réduit à vie.

1. Installation

Installez le SDK officiel via npm, pip ou téléchargez directement depuis notre CDN.

# npm
npm install @vgia/sdk

# pip
pip install vgia

# CDN
<script src="https://cdn.vgia.io/v1/vgia.min.js"></script>

2. Authentification

Récupérez votre clé API depuis le tableau de bord et incluez-la dans chaque requête.

import { VGIA } from '@vgia/sdk';

const vgia = new VGIA({
  apiKey: process.env.VGIA_API_KEY,
  region: 'eu-west',
});

3. Votre première recherche

Indexez une vidéo puis posez une question en langage naturel. VGIA retournera le timestamp exact, le transcript et la frame source.

// 1. Indexer la vidéo (asynchrone, ~1x la durée de la vidéo)
const job = await vgia.videos.index({
  url: 'https://vimeo.com/…',
  languages: ['fr', 'ar', 'en'],
});

// 2. Chercher
const answer = await vgia.ask({
  videoId: job.id,
  query: "Où l'orateur mentionne-t-il les réseaux neuronaux profonds ?",
});

console.log(answer.timestamp);   // "1:17:35"
console.log(answer.quote);       // transcript verbatim
console.log(answer.frameUrl);    // visual evidence

Référence API

Endpoints REST principaux. Chaque appel retourne du JSON structuré avec timestamp, source et niveau de confiance.

Méthode Endpoint Description
POST /v1/videos Indexer une nouvelle vidéo
GET /v1/videos/:id Statut d'indexation
POST /v1/ask Poser une question
GET /v1/transcripts/:id Récupérer le transcript
GET /v1/graph/:id Knowledge graph de la vidéo
DEL /v1/videos/:id Supprimer une vidéo

Rate limits

Les limites varient selon votre plan. Chaque réponse inclut les headers X-RateLimit-* pour suivre votre consommation en temps réel.

  • Starter : 1 000 requêtes / mois
  • Business : 10 000 requêtes / mois
  • Enterprise : illimité (fair-use)
